# Заборгованість за комунальні послуги — Шептицька громада

Сайт для перевірки заборгованості за комунальні послуги. Людина вводить номер договору (особового рахунку) і бачить адресу та суму боргу за кожною послугою: водопостачання, вивезення відходів, утримання будинку тощо. Послуги з боргом показуються першими.

Це гілка `version-2` — окрема версія лише для комунальних послуг. Портал місцевих податків (пошук за ПІБ) — у гілці `main`.

## Запуск

```bash
npm install     # один раз, встановити залежності
npm start       # сервер розробки на http://localhost:3000
npm run build   # зібрати сайт у папку dist/ для хостингу
```

## Бекенд

- `POST /check-utility-debt` з `{ contractNumber }` — заборгованість за номером договору.
  Відповідь: `{ data: [{ payerident, adress, paymentPurpose, charge }] }`, помилка — не-2xx з `{ message }`.

На сервері розробки (`npm start`) сайт бере тестові дані, у збірці (`npm run build`) — справжній бекенд.
Тестові договори: `123456` (є борги), `777777` (без боргу), інші — «нічого не знайдено».

## Де що лежить

- `src/pages/Utilities/` — сторінка (збирається як `index.html`)
- `src/sections/Debt/Debt.js` — пошук, валідація номера договору, картка з результатом
- `src/sections/` — шапка, перший екран, «Інструменти», футер
- `src/styles/` — кольори, типографіка, загальні стилі
