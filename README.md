# Портал місцевих податків Шептицької громади

Односторінковий сайт для перевірки та сплати місцевих податків онлайн. Зроблено на webpack, HTML, SCSS і JavaScript без фреймворків.

## Що зроблено

Сайт побудований на шаблоні «Портал місцевих податків», з якого раніше робили портали для інших громад (Ірпінь, Одеса). Шаблон адаптований під Шептицьку громаду і зверстаний за новими макетами.

**Верстка за макетами (мобільний і десктоп, перемикання на 768px):**
- шапка: герб, підпис «Портал місцевих податків Шептицької громади» (на десктопі), посилання «Інструменти», кнопка Telegram-бота;
- перший екран: тризуб і герб, заголовок, опис, поле пошуку за ПІБ, градієнтний фон (на десктопі — різнокольоровий);
- картка заборгованості: дата, ПІБ, податковий номер або дата народження, список податків із кодами та сумами; на десктопі — у дві колонки;
- «Якщо виникли запитання» з кнопкою переходу до Е-кабінету;
- «Інструменти» — три картки-посилання;
- Telegram-блок: на мобільному — нижня частина телефона з чатом бота; на десктопі — «Переваги», QR-код бота й телефон повністю;
- чорний футер: герби, адреса, контакти, соцмережі, PayForVictory, примітка про дизайн-систему «Дія».

**Логіка:**
- податки із заборгованістю показуються першими (від більшої суми до меншої), нульові — після них із неактивною кнопкою «Сплатити»;
- кнопка «Сплатити» відкриває вибір банку (Приват / МТБ Банк); під карткою — реквізити для оплати і завантаження PDF;
- стани поля пошуку: звичайний, заповнений, наведення, неактивний (під час запиту, зі спінером), помилка;
- зрозумілі повідомлення замість технічних помилок; ПІБ лишається в полі після пошуку;
- ПІБ у картці, реквізитах і PDF завжди в правильному регістрі (`тирко НАДІЯ` → `Тирко Надія`, з підтримкою подвійних прізвищ і апострофа);
- тестові дані автоматично вмикаються в сервері розробки й відсутні у збірці.

**Типографіка й стилі:**
- шрифт e-Ukraine, розміри H1–H8, Body, Small, Quote за таблицею типографіки (окремо для десктопу й мобільного) — міксини в `src/styles/typograpy.scss`;
- кольори, градієнти й брейкпоінти — у `src/styles/_vars.scss`.

**Виправлено в шаблоні:**
- логотипний варіант шрифту e-Ukraine Head підміняв звичайний — отримав окрему назву;
- у сервері розробки після правок зникали картинки з HTML-шаблону (`output.clean` вимкнено для dev);
- реквізити падали, якщо бекенд не передавав суму податку;
- прибрано попередження Sass про застарілий API;
- додано запасні системні шрифти, `webpack-merge` у залежності, оновлено `package.json`;
- прибрано секції й картинки інших громад (About, Navigation, комунальні борги, герби, QR-коди, фавікони).

## Запуск

```bash
npm install     # один раз, встановити залежності
npm start       # сервер розробки на http://localhost:3000
npm run build   # зібрати сайт у папку dist/ для хостингу
```

## Структура

- `src/pages/Home/` — шаблон сторінки, тут зібрані всі секції
- `src/sections/` — секції сторінки:
  - `Header` — шапка
  - `Intro` — перший екран із пошуком
  - `Debt` — пошук і картка заборгованості, логіка запитів до бекенду
  - `Questions` — «Якщо виникли запитання»
  - `Tools` — «Інструменти»
  - `Examples` — блок про Telegram-бота
  - `Footer` — футер
- `src/styles/` — змінні (кольори, брейкпоінти), типографіка, загальні стилі
- `src/assets/` — шрифти e-Ukraine, герби, картинки

## Бекенд

Запити йдуть із `src/sections/Debt/Debt.js`:

- `POST /info` з `{ username }` — пошук за ПІБ. Статус `300` означає, що треба уточнити дату народження.
- `POST /confirm` з `{ username, ident }` — уточнення, де `ident` — дата у форматі `yyyy-mm-dd`.
- `POST /payplace-pay` з `{ id, type }` — посилання на оплату через МТБ Банк.

На сервері розробки (`npm start`) сайт бере тестові дані (`USE_MOCK` у `Debt.js`). У збірці (`npm run build`) він завжди звертається до справжнього бекенду. Тестові ПІБ: «Тирко Надія Михайлівна», «Кравецький Володимир Іванович», «Шевчук Олена Петрівна», «Іваненко Іван Іванович» (дата народження `01.01.2000`).
