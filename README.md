# Портал місцевих податків Шептицької громади

Односторінковий сайт для перевірки та сплати місцевих податків онлайн. Зроблено на webpack, HTML, SCSS і JavaScript без фреймворків.

## Запуск

```bash
npm install     # один раз, встановити залежності
npm start       # сервер розробки на http://localhost:3000
npm run build   # зібрати сайт у папку dist/ для хостингу
```

## Структура

- `src/pages/Home/` — шаблон сторінки, тут зібрані всі секції
- `src/sections/` — секції сторінки:
  - `Header` — шапка
  - `Intro` — перший екран із пошуком
  - `Debt` — пошук і картка заборгованості, логіка запитів до бекенду
  - `Questions` — «Якщо виникли запитання»
  - `Tools` — «Інструменти»
  - `Examples` — блок про Telegram-бота
  - `Footer` — футер
- `src/styles/` — змінні (кольори, брейкпоінти), типографіка, загальні стилі
- `src/assets/` — шрифти e-Ukraine, герби, картинки

## Бекенд

Запити йдуть із `src/sections/Debt/Debt.js`:

- `POST /info` з `{ username }` — пошук за ПІБ. Статус `300` означає, що треба уточнити дату народження.
- `POST /confirm` з `{ username, ident }` — уточнення, де `ident` — дата у форматі `yyyy-mm-dd`.
- `POST /payplace-pay` з `{ id, type }` — посилання на оплату через МТБ Банк.

На сервері розробки (`npm start`) сайт бере тестові дані (`USE_MOCK` у `Debt.js`). У збірці (`npm run build`) він завжди звертається до справжнього бекенду. Тестові ПІБ: «Тирко Надія Михайлівна», «Кравецький Володимир Іванович», «Шевчук Олена Петрівна», «Іваненко Іван Іванович» (дата народження `01.01.2000`).

## Що ще треба заповнити

Шукайте в коді позначки `TODO` і заглушки `#` / `https://t.me/`:

- посилання на Telegram-бота: `Header.html`, `Examples.html`;
- три посилання в «Інструментах»: `Tools.html`;
- соцмережі громади та PayForVictory: `Footer.html`.
